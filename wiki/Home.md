# Insect Tracking Pipeline

End-to-end workflow for video-based tracking of insects (ants, flies, crickets)
— from parameter selection through track extraction.

**Tracking engine:** [TRex](https://trex.run) v2.x
**Hardware:** Raspberry Pi 4 + HQ camera module, ~30×20 cm arena, LED panel frame
**Stack:** Python, OpenCV, TRex (conda), uv

## How the pieces fit together

There are **two kinds of repository**:

**This repo (`tracking`)** is the tracker itself — generic, reused across every
experiment. You install it once per machine.

**A project repo** (one per experiment, e.g. `pain_killers`) holds that
experiment's configuration, analysis code, and results. It is generated by
this tracker and pins the tracker to a specific git tag, so the exact version
used to produce the data can always be recovered.

```
tracking/                        ← this repo, installed once
    pipeline/                     the tracker package
    new_project.py                generator GUI

pain_killers/                    ← one repo per experiment
    setup.py                      what a reviewer downloads and runs
    pyproject.toml                pins tracking@v0.3.0
    project.yaml                  tracker configuration
    1_pipeline.ipynb              preprocessing → tracking → postprocessing
    2_tracking/                   tracker working directory
    3_analysis/                   experiment-specific analysis
```

Projects live wherever you choose — they are **not** stored inside this repo,
since they contain large video and data files.
